# Bridging the Evaluation Gap: A Dual-Penalty Metric for Clinical Actionability in CGM Time-Series Forecasting

This repository contains the code, simulation environment (`simglucose`), and PyTorch implementation for comparing DLinear against the dual-penalty forecasting and actionability framework.

- **Notebook:** `cgm_simulation_and_modeling.ipynb`
- **Evaluation Metric:** Dual-Penalty Loss ($M_{dual}$)
